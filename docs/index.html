Try it on a Mi Box home screen

Three steps, nothing to install

  1. Turn on debugging on the Mi Box

    In Settings, Device Preferences, About, tap Build seven times. Then open Developer options and switch on USB debugging or Network debugging. You'll find the IP address under Network and Internet.

  2. Run the tool on a PC on the same network

    Download the exe, open it, pick your language and enter the Mi Box IP address. The first time, accept the prompt that appears on the TV.

  3. Review the list and confirm

    You see every package before anything changes. Confirm, and the tool removes them, saves a backup and shortens the interface animations.

Careful by design

Backup and restore
A JSON backup is saved before anything is removed. One menu choice brings every package back.
Dry run
See exactly what would be removed while changing nothing.
Protected packages
The launcher, settings, Play Services and other system parts are skipped even if they end up on the list.
ADB included
The Windows build ships with Android platform-tools. No install, no PATH to edit.
Honest results
Every package shows done or failed with ADB's real message, and a log is saved to mibox_debloater.log.
Package list export
Save everything installed on your device to a text file, handy for bug reports and pull requests.
Optional dexopt
Compiling every app takes 10 to 30 minutes on a Mi Box, so the tool asks before it starts.
Turkish and English
Pick the language at startup, or pass --lang.

Questions

      

        
Do I need to install ADB?
No. The Windows exe includes Android platform-tools. If you run main.py yourself, ADB must be in your PATH.

        
Can I undo it?
Yes. A backup is saved before anything is removed. Choose Restore in the menu or run the tool with --restore. A factory reset also brings everything back.

        
Windows shows a SmartScreen warning.
The exe is built with PyInstaller and isn't code-signed, which often triggers a warning. It is built by a public GitHub Actions workflow from the source in the repository, and you can build it yourself.

        
It can't connect to my Mi Box.
Check that the PC and the Mi Box are on the same network, Network debugging is on, and you accepted the prompt on the TV. ADB's real error is shown on screen and saved to mibox_debloater.log.

        
Does it work on other Android TV devices?
It is made for the Mi Box series. Other devices may work, but package names differ. Export the package list, review it, and run with --dry-run first.

        
Why is dexopt optional?
It compiles every app and can take 10 to 30 minutes on a Mi Box. Most of the speed-up comes from removing bloat and shortening animations.
